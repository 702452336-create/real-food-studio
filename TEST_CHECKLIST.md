# Chinese Food Engine V1 — Test Checklist

Use ordinary phone photos rather than professional reference photography.

Recommended pressure-test set:

1. Home-style stir-fry
2. Braised/spicy meat dish
3. Steamed/light dish
4. Soup/casserole/hotpot
5. Delivery/fast-meal dish
6. One Hero + dipping sauce
7. One Hero + rice + soup
8. Cropped vessel
9. Slightly cropped food edge
10. Dirty plate rim / accidental residue

For every result score:

- REAL: Is it still the same dish?
- PHOTO: Does it look professionally photographed?
- SELL: Can a restaurant use it commercially?

REAL failure = overall failure.
